# CRON Low-Level Machine Language (.cl) — Official Language Specification

**Version:** 88.0  
**Target Architecture:** 256-Core ($4 \times 4 \times 4 \times 4$) 4D-Torus Photonic/Neuromorphic Processor  
**Paradigm:** Machine-Native, AI-Native, Deterministic 128-Bit VLIW  

---

## 1. Философи ба Зорилго (Architectural Philosophy)

`.cl` (Cognitive Low-level) бол зүгээр нэг компиляторын завсрын хоёртын файл бус, харин **биет цахиур (RTL) болон хиймэл оюун ухаанд (AI Agent / Vibe Coder) шууд зориулагдсан бие даасан програмчлалын хэл** юм.

* **Хүмүүст зориулсан `.cr`:** Өндөр түвшний сэтгэхүй, шугаман төрөл (`lin`), амьдралын хугацааны бүсчлэл (`region`), логик дүрэм.
* **AI болон машинд зориулсан `.cl`:** Ямар ч хоёрдмол утгагүй (Zero Ambiguity), яг 10 тэмдэгттэй, 8 дахь тэмдэгт дээрээ алдаа илрүүлэх Parity хамгаалалттай, 1 багцад 4 үйлдэл зэрэгцүүлсэн 128 битийн VLIW хэл.

---

## 2. Кодын Бүтэц ба Багцын Бүтэц (Bundle Structure)

`.cl` хэлний эх код нь тактын дараалал бүхий VLIW багцуудаас бүрдэнэ:

```cl
B<cycle_index>: <Slot_0> <Slot_1> <Slot_2> <Slot_3>
```

* **Багцын өргөн:** 128 бит (32 бит $\times$ 4 слот).
* **Слотын тоо:** Багц бүр яг 4 слоттой.
* **Такт:** Цахиурын 1 тактанд 4 слот зэрэгцээ ажиллана.

---

## 3. Слотын 10 Тэмдэгтийн Бүтэц (Slot Token Anatomy)

Слот бүр нь яг **10 ASCII тэмдэгтэд** багтана:

| Байрлал (Индекс) | Зориулалт | Утга / Жишээ | Тайлбар |
|---|---|---|---|
| **0** | Prefix | `_` эсвэл `'` | `_`: Үндсэн команд, `'`: Шууд утга ачаалагч |
| **1 .. 2** | Opcode | `OP`, `FA`, `PO`, `MD`, `BK`, `BL`, `RF`, `GU`, `ST`, `SY`, `RS`, `PK`, `TL`, `YD`, `SP`, `FJ`, `DW`, `SB`, `SH`, `RC`, `HL` | 2 тэмдэгттэй үндсэн үйлдэл |
| **3 .. 4** | Dest Reg | `00` .. `0F` ($R_0$ .. $R_{15}$) | Үр дүнг бичих регистр |
| **5** | Mode Delim | `$`, `#`, `@` | Хаяглалт ба үйлдлийн горим |
| **6** | Src Reg | `0` .. `F` | Эх регистр эсвэл параметрийн дээд хагас |
| **7 (8 дахь)** | **Parity Token** | Хекс / Алфанумерик | **Өгөгдлийн бүрэн бүтэн байдлын Parity хамгаалалт** |
| **8** | Immediate | `0` .. `F` | Шууд утга эсвэл параметрийн доод хагас |
| **9 (10 дахь)** | Terminator | `>` эсвэл `!` | `>`: Хэвийн үйлдэл, `!`: Зогсолт (`_HLT00008!`) |

## 4. Опкодын Лавлах (Opcode Set by 6 Brains)

### 1. Фотоник Оптик Тархи (Brain 2 — Photonic GEMM)
* `_OP`: MZI фотоник долгионы матриц интерференц үржвэр ($R_4$).
* `_FA`: Авто-градиент уламжлалын фазын тэмдэглэгээ (`Forward Autodiff Tap`).

### 2. Буцах Термодинамик Санах Ой (Brain 3 — Reversible Memory)
* `_BK`: Санах ойгүй урвуу градиент сэргээх буцах үйлдэл ($F^{-1}$).
* `_RF`: Мэдээллийн алдагдалгүй Фредкин хаалганы хослол (`Reversible Swap`).

### 3. Биологийн Синапс (Brain 4 — Neuromorphic STDP)
* `_ST`: Спайк цагийн зөрүүгээр синапсын жинг шинэчлэх (STDP plastic adaptation).
* `_GU`: Градиентийн алхмаар жин шинэчлэх (`$W \leftarrow W - \eta \cdot \nabla W$`).

### 4. Бэлгэдэл Учир Шалтгаан (Brain 1 — Causal Graph)
* `_SY`: Вектор төлөвийг бэлгэдлийн графын ID болгон шахах (`Symbolify`).

### 5. Тооцооллын Хурдасгуур ба Предикат (ALU & SIMD)
* `_PK`: 32-битийн өгөгдлийг 16 ширхэг 2-бит тернари утга болгон багцлах (`Sub-byte Packing`).
* `_MD`: 16 ширхэг 2-бит тернари векторын 1-такт үржвэр хуримтлуулалт (BitNet 1.58b MAC).
* `_PO`: Клок-гейтинг дулаан дарах 4-сувагт предикат маск (`Predicated SIMD`).

### 6. Сүлжээ, Асинхрон ба Хамгаалалт (4D Torus & Metacognition)
* `_TL`: 4D Торусын физик координатаас матрицын блокийн суурь хаяг олох.
* `_SP`: Хоёрдогч шилэн утсыг сэрээх (`Spawn Fiber 1`).
* `_YD`: Сүлжээний саатал дээр 0-такттай утас солих (`Fiber Yield`).
* `_FJ`: Хоёрдогч утсын үр дүнг нэгтгэх (`Fiber Join`).
* `_DW`: DMA гадаад дамжуулалт хүлээх (`DMA Wait`).
* `_SB`: Үр дүнг 4D Торусын 8 хөрш рүү нэгэн зэрэг цацах (`Spatial Broadcast`).
* `_SH`: Өөрийгөө хамгаалах харуулыг тохируулах (`Self-Healing Sentry`).
* `_RC`: Гэмтэл гарсан үед ашиглах нөөц суваг нээх (`Re-route Channel`).
* `_RS`: Бүсийн аренаг 0 тактанд арчих (`Region Arena Reset`).
* `_HL`: Тооцооллыг алдаагүй дуусган цөмийг зогсоох (`Halt`).

## 5. Гар Аргаар Бичсэн `.cl` Програмын Жишээ

AI инженер шууд дараах 6 тактын `.cl` машины кодыг бичиж цахиурт тушаал өгнө:

```cl

; CRON Direct Machine Language Program
; Target: 256-Core 4D-Torus Bare Metal

B0001: '=00#0A04> '=10#040B> _SH00$1B4> _SP00#088>
B0002: _PK020$20> _TL030$04> _ST00$110> _YD08$205>
B0003: _OP041$0E> _FA054$20> _PO064$32> _RC07$205>
B0004: _MD082$26> _BK095$01> _BL0A3$10> _RF0B6$04>
B0005: _GU049#00> _ST0C8$54> _SY0D7$28> _RS00#04B>
B0006: _FJ048#00> _DW00$105> _SB04$105> _HLT00008!
```

## 6. Түүлчэйний Дэмжлэг (Toolchain Commands for `.cl`)

1. **`.cl` кодыг шалгах (Syntax, Parity, Hazard check):**
   ```bash
   cron check program.cl
   ```
2. **`.cl` кодыг 256 цөм дээр шууд ажиллуулах:**
   ```bash
   cron sim program.cl
   ```
3. **`.cl` кодыг дээд түвшний `.cr` болгон сэргээх:**
   ```bash
   cron decompile program.cl -o blueprint.cr
   ```
