# 4D Гипер-Бөмбөрцөг Тооцооллын Бүрэн Математик Загвар (4D Hypersphere 4-Snake Topology)

Энэхүү баримт бичиг нь 4 хэмжээст орон зайд 4 могойн урсгалаар бөмбөрцгийн эзлэхүүнийг 100% тэгш хуваарилах, `0` төлөвийн фазын түгжээгээр уртын тэнцвэрийг хадгалах, болон мөргөлдөөнгүй "тахир зүү"-ний геометрийн баталгааг цогцоор нь нэгтгэсэн албан ёсны техникийн загвар юм.

---

## 1. Үндсэн Асуудал ба `0` Төлөвийн Засвар

### Тулгарч байсан өмнөх алдаа
1. Хэрэв могой `0` команд аваад орон зайд үхмэл зогсолт хийвэл түүний туулсан замын урт $L_{dead} < T + 1$ болж богиносно.
2. Урт нь богиноссон могойн эзлэхүүн $V_k < \frac{1}{4} V_{total}$ болж багасан, бусад 3 могой нь илүү их талбай хучиж, бөмбөрцгийн дотор хоосон нүх/цоорхой (void) үүсэх эрсдэлтэй байсан.

### Бодит засвар: `0` Төлөвийн Фазын Түгжээ (Phase-Lock Orbit)
* `0` төлөв бол үхмэл зогсолт биш. Орон зайн координат шилжихгүй ($W, X, Z$ хэвээр үлдэнэ) боловч тоног төхөөрөмжийн тактын тоолуур дээр өөрийн тэнхлэг дэх бичил фазын эргэлт (Phase-Lock Cycle) явагдана.
* Шилжилтийн метрик нормын хууль:
  $$\|\mathbf{\Delta}_k(t)\| = 1, \quad \forall t \ge 0, \; \forall k \in \{1, 2, 3, 4\}$$
* Могой шилжсэн ч бай, байрандаа `0` төлөвт байсан ч бай туулсан замын нийт урт цаг хугацааны такт $T$-тэй яг тэнцүү өснө:
  $$L_k = T + 1$$
* Бүх 4 могойн замын урт цаг ямагт яг тэнцүү ($L_1 = L_2 = L_3 = L_4$) тул бөмбөрцгийн эзлэхүүн ямар ч цоорхойгүйгээр **яг $25\% \times 4 = 100\%$ тэнцүү хуваагдана**.

## 2. 4D Топологи ба Координатын Суурь Орон Зай

Орон зайг 4 могойн урсгал ($k \in \{1, 2, 3, 4\}$), төвөөс гадагшлах 99 давхарга ($W$), болон гадаргуугийн $360^\circ \times 360^\circ$ хос эргэлтийн огтлолцол ($X, Z$)-ээр тодорхойлно:

$$\mathcal{M}^4 = \left\{ (W, X, Z, k) \;\middle\vert\; W \in [0, 99], \; X \in [0, 99], \; Z \in [0, 99], \; k \in \{1, 2, 3, 4\} \right\}$$

Цаг хугацааны дискрет такт $t$-д $k$-р могойн төлөвийн вектор:

$$\mathbf{P}_k(t) = \begin{pmatrix} W_k(t) \\ X_k(t) \\ Z_k(t) \end{pmatrix} \in \mathbb{Z}_{100}^3$$

* **$W_k(t) \in [0, 99]$:** Төвөөс зугтах радиус давхарга ($W=0$ төв цэг, $W=99$ гадаад гадарга). 7-бит маск: `W & 0x7F`.
* **$X_k(t) \in [0, 99]$:** Эхний чиглэлийн $360^\circ$ бүтэн эргэлтийн дискрет хуваалт (7-бит).
* **$Z_k(t) \in [0, 99]$:** Эсрэг чиглэлийн $360^\circ$ бүтэн эргэлтийн дискрет хуваалт (7-бит).
* **99:99 Гадаргуугийн нэгдсэн код ($C_k$):** Хоёр перпендикуляр өнцгийг битийн түвшинд нэгтгэсэн 14-битийн координат:
  $$C_k(t) = (X_k(t) \ll 7) \mid Z_k(t), \quad C_k \in [0, 16383]$$

## 3. "Тахир зүү"-ний Баталгаа ба Мөргөлдөөнгүй Нөхцөл

Бөмбөрцгийг нэвт харах 3D/2D төсөөлөл дээр хоёр өөр могой $i \neq j$ нэг цэгт давхцаж харагдах нөхцөл:

$$\Phi_{3D}(\mathbf{P}_i(t)) = \Phi_{3D}(\mathbf{P}_j(t)) \iff \begin{cases} X_i(t) = X_j(t) \\ Z_i(t) = Z_j(t) \end{cases}$$

Энэ үед 4D бодит орон зай дахь хоорондын зай:

$$d_{4D}(\mathbf{P}_i(t), \mathbf{P}_j(t)) = \sqrt{\left(W_i(t) - W_j(t)\right)^2 + \left(X_i(t) - X_j(t)\right)^2 + \left(Z_i(t) - Z_j(t)\right)^2}$$

Гадаргуугийн давхцал ($X_i = X_j \land Z_i = Z_j$) үүсэх үед:

$$d_{4D}(\mathbf{P}_i(t), \mathbf{P}_j(t)) = |W_i(t) - W_j(t)|$$

**"Тахир зүү"-ний хатуу нөхцөл:**

$$\forall i \neq j: \quad \left(X_i(t) = X_j(t) \land Z_i(t) = Z_j(t)\right) \implies |W_i(t) - W_j(t)| \ge 1$$

Могойнууд өнцгөөрөө давхцсан ч $W$ давхарга нь зөрдөг тул 4D бодит зайд бие биеийнхээ доогуур/дээгүүр чөлөөтэй зөрнө. Мөргөлдөөний магадлал $0.00\%$.

## 4. Хөдөлгөөний Оператор ба Эзлэхүүн Хадгалалт

Такт $t \to t+1$ шилжилтийн вектор:

$$\mathbf{P}_k(t+1) = \mathbf{P}_k(t) \oplus \mathbf{\Delta}_k(t)$$

$$\mathbf{\Delta}_k(t) = \begin{pmatrix} \Delta W_k(t) \\ \Delta X_k(t) \\ \Delta Z_k(t) \end{pmatrix}$$

1. **Дүүргэгч хөдөлгөөн (Төлөв $\neq 0$):**
   $$\|\mathbf{\Delta}_k(t)\| = |\Delta W_k(t)| + |\Delta X_k(t)| + |\Delta Z_k(t)| = 1$$
2. **Зангуу / Хүлээлт (`0` Төлөв):**
   Координат хөдлөхгүй ($\Delta W = 0, \Delta X = 0, \Delta Z = 0$), гэвч фазын регистр 1 такт нэмэгдэнэ:
   $$\|\mathbf{\Delta}_k(t)\| = 1 \quad (\text{Phase Orbit Lock})$$

### Эзлэхүүний тэнцвэрийн хууль:
$$L_1(T) = L_2(T) = L_3(T) = L_4(T) = \sum_{t=0}^{T} \|\mathbf{\Delta}_k(t)\| = T + 1$$

$$V_{total} = \sum_{k=1}^4 V_k, \quad V_1 = V_2 = V_3 = V_4 = \frac{1}{4} V_{total} \quad (100\% \text{ тэгш хуваарилалт})$$

## 5. Орон зайн Проекцууд (2D $\leftrightarrow$ 3D $\leftrightarrow$ 4D)

### 2D Проекц (Цагийн зүүний загвар):
$$r_{2D}(t) = W_k(t) + \sqrt{X_k(t)^2 + Z_k(t)^2}$$
$$\theta_{2D}(t) = \operatorname{atan2}(Z_k(t), X_k(t))$$
$$\mathbf{v}_{2D}(t) = \begin{pmatrix} r_{2D}(t) \cos(\theta_{2D}(t)) \\ r_{2D}(t) \sin(\theta_{2D}(t)) \end{pmatrix}$$

### 3D Проекц (Бөмбөрцгийг нэвт харах):
$$\alpha = \frac{2\pi \cdot X_k(t)}{100}, \quad \beta = \frac{2\pi \cdot Z_k(t)}{100}$$
$$\mathbf{v}_{3D}(t) = \frac{W_k(t)}{99} R_{max} \begin{pmatrix} \cos(\alpha) \cos(\beta) \\ \sin(\alpha) \cos(\beta) \\ \sin(\beta) \end{pmatrix}$$

### 2D $\equiv$ 4D Тэгшитгэх урвуу хувиргалт (Изометрийн зангуу):
3-р могойг лавлах зангуу тэнхлэг болгон авч хавтгайд дэлгэнэ:
* **Шууд хувиргалт ($4D \to 2D$):**
  $$\Delta U_k = W_k(t) - W_3(t)$$
  $$\Delta V_k = (C_k(t) - C_3(t)) \ \& \ \text{0x3FFF}$$
* **Буцаан сэргээх урвуу хувиргалт ($2D \to 4D$):**
  $$W_k(t) = W_3(t) + \Delta U_k$$
  $$C_k(t) = (C_3(t) + \Delta V_k) \ \& \ \text{0x3FFF}$$
  $$X_k(t) = C_k(t) \gg 7, \quad Z_k(t) = C_k(t) \ \& \ \text{0x7F}$$

Энэ хувиргалт нь харилцан нэг утгатай (bijective) тул мэдээллийн алдагдал $0.00\%$ байна.

## 6. Техник Хангамж ба VLIW Битийн Архитектур

* **Үржүүлэгчгүй, хуваагчгүй:** `/` ба `%` үйлдлийг халж, зөвхөн битийн шилжилт (`>>`, `<<`) ба маск (`&`)-аар тооцно.
* `MASK_7BIT = 0x7F` (0..127)
* `MASK_14BIT = 0x3FFF` (0..16383)
* `SHIFT = 7`
* **Zero-Overhead Hardware Loop:** `if/else` салбарлалтгүй, яг заасан тактын тоогоор тоолуураар буцаж эргэнэ.
